**تعداد جلسات:** ۸  
**مخاطب:** معلم‌های کامپیوتر

| جلسه | موضوع |
|------|--------|
| ۱ | کلاس و آبجکت، attribute، متد، self |
| ۲ | `__init__`، encapsulation، property |
| ۳ | وراثت (inheritance) |
| ۴ | polymorphism، override |
| ۵ | abstract class، interface در پایتون |
| ۶ | magic methods (`__str__`, `__repr__`, ...) |
| ۷ | composition vs inheritance |
| ۸ | پروژه کوچک OOP |
