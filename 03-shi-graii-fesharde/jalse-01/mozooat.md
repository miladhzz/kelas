# جلسه ۱ — موضوعات تدریس‌شده

## مفاهیم پوشش‌داده‌شده

1. **تفاوت کلاس و آبجکت (instance)**
2. **Instance attribute** — ویژگی مخصوص هر آبجکت
3. **Class attribute** — ویژگی مشترک بین همه آبجکت‌ها
4. **متدها** — توابع داخل کلاس
5. **`self`** — چرا لازم است و به چه چیزی اشاره می‌کند
6. **`__init__`** — سازنده، پارامترها، چرایی استفاده
7. **متد ساده** — ساخت و فراخوانی
8. **تفاوت `__init__` با متدهای دیگر**
9. **تفاوت instance attribute، class attribute و local variable**

## نکات کلیدی برای مرور

- کلاس = قالب (blueprint) | آبجکت = نمونه ساخته‌شده از قالب
- `self` = همان آبجکت فعلی که متد روی آن صدا زده شده
- `__init__` فقط یک‌بار هنگام ساخت آبجکت اجرا می‌شود
- متدهای دیگر هر زمان که صدا زده شوند اجرا می‌شوند
- متغیر محلی فقط داخل همان متد زنده است و با attribute اشتباه گرفته نشود
