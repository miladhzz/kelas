2. یک **ویس ۳ تا ۵ دقیقه‌ای** ضبط کنید و توضیح دهید

## بخش ۱ — تکمیل کد

فایل `tamrin_kelas.py` را باز کنید و قسمت‌های `# TODO` را کامل کنید.

کلاس `Teacher` (معلم) را طوری پیاده‌سازی کنید که:
- هر معلم **نام** و **رشته تدریس** داشته باشد (instance attribute)
- تعداد کل معلم‌ها در سیستم شمارش شود (class attribute)
- متد `moarefi()` معرفی کوتاه معلم را چاپ کند
- متد `ezafe_kelas(نام_کلاس)` یک کلاس جدید به لیست کلاس‌های معلم اضافه کند

## بخش ۲ — ویس توضیحی (اجباری)

ویس خود را در گروه/پیام خصوصی بفرستید. در ویس **حتماً** به این سوالات جواب دهید:

### سوال ۱
> تفاوت `Teacher` و `m1 = Teacher("علی", "پایتون")` چیست؟

### سوال ۲
> `self.name` چیست؟ `Teacher.tedad_kol` چیست؟ تفاوتشان را بگویید.

### سوال ۳
> چرا در `__init__` از `self` استفاده می‌کنیم ولی وقتی `m1.moarefi()` صدا می‌زنیم `self` نمی‌نویسیم؟

### سوال ۴
> در متد `ezafe_kelas` اگر بنویسیم `nam = نام_کلاس` به‌جای `self.kelas_ha.append(...)`، چه تفاوتی ایجاد می‌شود؟

### سوال ۵
> `__init__` و `moarefi()` هر دو متد هستند. یک تفاوت مهم بین‌شان چیست؟

## معیار ارزیابی

| معیار | توضیح |
|--------|--------|
| کد درست اجرا شود | بدون خطا اجرا شود و خروجی منطقی بدهد |
| تفکیک attributeها | instance / class / local را درست تشخیص دهند |
| درک self | بدانند self به کدام آبجکت اشاره می‌کند |
| تفاوت init و متد | زمان اجرا و نقش هر کدام را بدانند |
